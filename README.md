# Qian Qin Personal Website

This is the source for Qian Qin's personal academic website. It is a static React site built with Vite and is ready to publish with GitHub Pages.

The included GitHub Actions workflow builds and deploys the site automatically. It detects whether the repository is a root user site such as `qianqin11.github.io` or a project site such as `qianqin11.github.io/Personal_Website`, so no path setting needs to be changed by hand.

## Publish on GitHub Pages

1. Create a repository on GitHub.
   - Name it `qianqin11.github.io` for the address `https://qianqin11.github.io/`.
   - Use any other repository name for an address such as `https://qianqin11.github.io/Personal_Website/`.
2. Push this project to that repository. For example, replace `<repository-name>` below with the name you chose:

   ```powershell
   git remote add origin https://github.com/qianqin11/<repository-name>.git
   git branch -M main
   git push -u origin main
   ```

3. In the GitHub repository, open **Settings → Pages**. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Open the **Actions** tab and run **Deploy website to GitHub Pages**, or push another change to `main` or `master`.

The completed workflow shows the published URL. Every later push to `main` or `master` rebuilds and republishes the site.

Do not commit `dist`; it is generated by the workflow and uploaded directly to GitHub Pages.

## Work on the site locally

Install Node.js 22.13 or newer and pnpm, then run:

```powershell
pnpm install
pnpm dev
```

Open the local URL shown in the terminal, normally `http://localhost:5173`. Stop the preview with `Ctrl+C`.

Before publishing, create a production build:

```powershell
pnpm build
```

The static website is written to `dist`. To inspect that build locally, run:

```powershell
pnpm preview
```

## Edit page content

Open `app/page.tsx` and find the visible heading or text you want to update. External links follow this pattern:

```tsx
<a href="https://example.com" {...externalProps}>
  Link text
</a>
```

Each publication is one complete block:

```tsx
<article>
  <p>Publication information goes here.</p>
</article>
```

Copy a complete block to add an article, keep the list newest to oldest, and place journal names inside `<em>...</em>`.

## Replace images

Replace the portrait with another file named `public/qian-qin.jpg`. A vertical image with a 4:5 aspect ratio works best.

Replace the social card with another file named `public/og.png`. If its dimensions change, update `og:image:width` and `og:image:height` in `index.html`.

## Pushing update to GitHub

If you updated `README.md`, `app/page.tsx`, and `globals.css`, in Powershell, run:

```powershell
git add README.md app/page.tsx app/globals.css
git commit -m "A short description of the update "

git pull --rebase origin main
git push origin main
```

## How repository paths are handled

The deployment workflow asks GitHub Pages for its actual base path and URL, then passes both to Vite during the build. Vite prefixes scripts, styles, the portrait, and the favicon correctly, while the same URL is written into canonical and social-sharing metadata. This also adapts automatically if a custom domain is configured in GitHub Pages.
